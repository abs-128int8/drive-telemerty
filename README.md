# drive-telemetry
This app displays driving telemetry data:
- Speed
- Acceleration
- Sector Logs

[CLICK HERE](https://abs-128int8.github.io/drive-telemetry/) to use the app

## How to Use
1. Mount your phone on the phone holder.
2. Tap the G-Force Viewer to calibrate and start recording.

## What Is a Sector
- Recording starts once your car has been moving above 5 km/h for 1 second.
- Recording stops once your car has been going below 2 km/h for 3 seconds.
- Tap a sector log to view the telemetry data recorded for that sector.
